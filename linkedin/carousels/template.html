03 / CODE — Exemple de code avec terminal
→ Pattern #1 : Event-driven
Du couplage direct à l'event bus
order_service.rb
# ❌ Avant — couplage fort
def create_order(params)
order = Order.create!(params)
EmailService.send_confirmation(order)
StockService.decrement(order.items)
# ✅ Après — event bus
def create_order(params)
order = Order.create!(params)
EventBus.publish("order.created", order)
# → chaque service écoute indépendamment
